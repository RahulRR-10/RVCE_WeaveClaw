# 🔄 9. ROUTINE MANAGEMENT

Routines are automated command chains stored in `~/.openclaw/routines.json`. You can READ, CREATE, EDIT, and DELETE routines based on user requests.

## 📋 Viewing Routines

```bash
# List all available routines
cat ~/.openclaw/routines.json | jq '.routines | keys[]'

# Read a specific routine
cat ~/.openclaw/routines.json | jq '.routines["routine-name"]'

# View all routine descriptions
cat ~/.openclaw/routines.json | jq -r '.routines | to_entries[] | "\(.key): \(.value.description)"'
```

## 🚀 Running Routines

When a user's message matches a routine keyword, **ALWAYS confirm before executing**. Extract variables from their message naturally.

```bash
# Run a routine with no variables
bash ~/routine_runner.sh gym-mode

# Run a routine with variables
bash ~/routine_runner.sh search-youtube --QUERY "funny+cat+videos"
bash ~/routine_runner.sh set-reminder --TASK "buy milk" --TIME "5pm"
bash ~/routine_runner.sh play-music --QUERY "lofi hip hop"
```

**Workflow for running routines:**
1. Match user message to a routine using the `keywords` array
2. Extract named variables from their message (e.g., "remind me to buy milk at 5pm" → TASK="buy milk", TIME="5pm")
3. **Confirm with user**: "I'll run [routine name]: [summary]. OK?"
4. Wait for confirmation
5. Execute with `bash ~/routine_runner.sh <name> --VAR "value"`
6. Report results back to user

## ➕ Creating Routines

When a user asks to create a routine, add it to `routines.json`:

```bash
# Create a new routine
cat ~/.openclaw/routines.json | jq '.routines["routine-id"] = {
  "keywords": ["trigger1", "trigger2"],
  "match_type": "any",
  "description": "Description of what it does",
  "variables": ["VAR1", "VAR2"],
  "commands": [
    {"type": "control", "action": "wake"},
    {"type": "control", "action": "brightness", "value": 200},
    {"type": "delay", "value": 1},
    {"type": "control", "action": "open-app", "value": "com.package.name"},
    {"type": "control", "action": "open-url", "value": "https://example.com?query={VAR1}"},
    {"type": "agent", "action": "Do something with {VAR1} and {VAR2}"},
    {"type": "delay", "value": 2},
    {"type": "agent", "action": "Say 'Routine complete.'"}
  ]
}' > /tmp/routines_temp.json && mv /tmp/routines_temp.json ~/.openclaw/routines.json
```

**Routine structure:**
- `keywords`: Array of words/phrases that trigger this routine
- `match_type`: `"any"` (contains), `"exact"` (full match), or `"prefix"` (starts with)
- `description`: Human-readable description
- `variables`: Array of variable names like `["TASK", "TIME"]` — these become `{TASK}` and `{TIME}` in commands
- `commands`: Array of steps (executed in order):
  - `{"type": "control", "action": "action", "value": "optional"}` → calls `phone_control.sh`
  - `{"type": "control", "action": "action", "repeat": N}` → repeats N times
  - `{"type": "agent", "action": "task"}` → calls `phone_agent.sh` with task description
  - `{"type": "delay", "value": N}` → waits N seconds

**Variable substitution:** `{VAR}` in command values gets replaced with the actual value. For URLs, use `+` or `%20` for spaces.

## ✏️ Editing Routines

```bash
# Add a command to an existing routine
cat ~/.openclaw/routines.json | jq '.routines["night-mode"].commands += [{"type": "control", "action": "vol-down", "repeat": 5}]' > /tmp/routines_temp.json && mv /tmp/routines_temp.json ~/.openclaw/routines.json

# Modify a command value
cat ~/.openclaw/routines.json | jq '.routines["morning-routine"].commands[1].value = 180' > /tmp/routines_temp.json && mv /tmp/routines_temp.json ~/.openclaw/routines.json

# Add a keyword
cat ~/.openclaw/routines.json | jq '.routines["gym-mode"].keywords += ["hit workout"]' > /tmp/routines_temp.json && mv /tmp/routines_temp.json ~/.openclaw/routines.json

# Add a variable
cat ~/.openclaw/routines.json | jq '.routines["gym-mode"].variables += ["WORKOUT_TYPE"]' > /tmp/routines_temp.json && mv /tmp/routines_temp.json ~/.openclaw/routines.json
```

## 🗑️ Deleting Routines

```bash
# Delete a routine
cat ~/.openclaw/routines.json | jq 'del(.routines["routine-id"])' > /tmp/routines_temp.json && mv /tmp/routines_temp.json ~/.openclaw/routines.json
```
